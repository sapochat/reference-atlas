# Reference Atlas

Inspect the existing project before designing. For every target section, record source, trait to borrow, trait not to copy, build implication, mobile behavior, and attribution. State which source controls typography, layout, motion, and imagery when references conflict.

Build a complete first pass before polishing. Collect concrete defects, batch related repairs, then audit typography, color, hierarchy, motion, mobile, copy, performance, accessibility, and reference fidelity. Verify real routes at desktop, tablet, and mobile widths; check console errors, network failures, overflow, touch behavior, and reduced motion.
