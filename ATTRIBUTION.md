# Attribution

The section-by-section reference collection idea was adapted from @monokern's
portfolio walkthrough:
https://x.com/monokern/status/2071246711222055363

This repository is an independent implementation. It adds a versioned atlas
schema, source relationships, conflict hierarchy, attribution and requirement
fields, deterministic validation and explicit readiness diagnostics. No source
code or visual assets from that walkthrough are distributed here.

The SVG diagrams and example documents are synthetic repository examples. They
are not screenshots of a tested website and do not establish browser, visual,
accessibility or performance verification.

The CLI records author-supplied attribution and review assertions. It does not
determine ownership, verify licensing rights or grant permission to reuse any
third-party material. Obtain any required permission separately.

The application uses Python's standard library at runtime. Development tests use
separately installed Markdown and JSON Schema validators; their source code is
not vendored in this repository. Repository code and synthetic assets are covered
by the accompanying MIT license.
